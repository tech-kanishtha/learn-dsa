When we want to print the unique numbers from the vecotr  (or array ) then we can approach the problem using the BITWISE XOR operator
BITWISE XOR (^)
1^1 = 0 
0^0 = 0
1^0 = 1
0^1 = 1
For example if we have vector v = {1 , 3 , 4 , 4 , 3}
If the numbers that we not unique : were in the pair as negative and positive then it would have been much easier for us to just add them and cancel it out after it so we will use xor for this thing
in binary 3 = 11 
we will take the XOR of it with itself -> 3^3 = 11^11 = 00 = 0
so it gets cancelled out and at the end only unique number will be left
So basically what we'll do is : 1 ^ 3 ^ 4 ^ 4 ^ 3 = 1
( n ^ n = 0)
( n ^ 0 = n)
